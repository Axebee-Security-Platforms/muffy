Where muffy's know-how lives

Each agent carries its own methods in its reference files. No agent needs an outside skill installed. One optional skill, impeccable, is used by the Orchestrator at the design gate.

How an agent loads what it needs

  1. The agent file (.claude/agents/<agent>.md) has a Load on demand table.
  2. It reads purpose, required-inputs and rules-and-guardrails at start, workflow before acting, and principles only on a judgment call.
  3. Nothing is preloaded through skills:. A preloaded skill puts its whole text into every spawn, and an agent that needs a skill nobody installed may break.

The one optional skill

impeccable  Orchestrator only, step 3c (references/design-review.md).

  1. The designer hands off the canvas source. It has no browser, so it cannot see the canvas as it renders.
  2. The Orchestrator publishes the canvas, opens it at desktop and phone width, and runs the impeccable critique.
  3. high findings go back to the designer (counted at loop point 3c:designer); the rest go to you at pause:design-review.

Not installed → the review is skipped and the gate says so. Nothing else changes.
