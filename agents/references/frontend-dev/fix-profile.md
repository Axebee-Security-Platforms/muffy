## Fix Profile

Read this only when the prompt has `Profile: fix`. The task has `fix.md` instead of `ac.md`, `contract.md`, `brief.md` and `design.md`; do not look for those.

**You do not diagnose.** The `debugger` found the cause and the `auditor` confirmed it before you were spawned; you are a fresh spawn, so read what they left, in this order: `fix.md` (`## Cause`, `## Repro`, `## Evidence`, `## AC`), the debugger's hand-off (`diagnosis.files`, `owner`, `severity`) and the auditor's hand-off (`audit`). If `fix.md` says `## Audit` (`cause not audited, risk accepted by the user`), the cause is unproven: build the regression test first and say in your summary whether it failed for the reason `## Cause` gives. Do not talk to either agent; if the cause looks wrong, say so in a blocker and stop (see below).

**Step 4: fix.** Work inside your worktree. Change only your own files, plus tests: with `owner` `both`, those listed under your side in `diagnosis.owner_files` (`FE` or `BE`); otherwise `diagnosis.files`. A file you need that is not on your list is a blocker, not an edit. Add a regression test that fails before the fix and passes after; run it both ways and say so. The `## Repro` of `fix.md` is where to start. If no test can reach the bug where it happens (the only seam is too shallow to replay the chain that triggered it), a test there gives false confidence: say so in the hand-off summary and mark the AC `manual` in `fix.md` with the manual check named; if the structure itself is why the bug cannot be locked down, hand off `status: blocked` with a blocker `owner: Architect`. Cosmetic: use existing design-system tokens only, no new component, and show the visual check named in the AC. More than 5 source files, or a need to touch the contract, a dependency or the stack: stop, do not work around it, and hand off `status: blocked` with a blocker `owner: Architect` whose `problem` says which limit was hit. The Orchestrator promotes the task to the full flow. A fix that does not make the repro go green means the cause was wrong: hand off `status: blocked` with a blocker naming the repro result; the Orchestrator re-opens the diagnosis. Hand-off step `4`, `ac_ids_done` from `fix.md`.

Brain note: append at most 5 lines (cause, fix, files, test). Skip the PR diagram.
