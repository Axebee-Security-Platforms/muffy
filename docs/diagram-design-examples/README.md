# diagram-design examples

Reference copies of the example diagrams from [diagram-design](https://github.com/cathrynlavery/diagram-design) (MIT, see `LICENSE`, copyright Cathryn Lavery), version 2.6. They show what each of its 45 visual types looks like, in light (`example-<type>.html`), dark (`-dark`), full-editorial (`-full`) and animated (`-animated`) variants.

These are for people and for design research only. They are **not** muffy diagrams: they are hand-written SVG with their own style (Geist and Instrument Serif fonts from Google Fonts, no blueprint grid) and do not pass `check-diagram.mjs`. Agents must keep drawing from `skills/muffy/templates/diagram.html`; this folder is outside `skills/` so it is never installed or loaded.
